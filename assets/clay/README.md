# Пластилиновые игровые слои

Созданы 8 октября 2026 года с помощью ImageGen по утверждённому [макету](../../design/concepts/aist-menu-clay-v2.png). Эти изображения — отдельные игровые элементы; слова, алфавит и слоты рисуются HTML/CSS.

| Файл | Назначение | Ключевые требования к исходному запросу |
| --- | --- | --- |
| `meadow-bg.png` | Общий фон меню и урока | Только тихая долина, озеро и дальние размытые синие холмы; без карточек, текста и персонажей. |
| `story-card.png` | Пустая карточка меню | Толстая пластилиновая рамка и пустая голубая вставка, прозрачный фон; без текста и героя. |
| `stork-nest.png` | Аист в меню и на игровом поле | Добрый белый аист в гнезде, матовая лепка, прозрачный фон; без текста и декораций. |
| `stork-flying.png` | Полёт после предложения | Тот же белый аист с поднятыми крыльями, прозрачный фон. |
| `hedgehog-ball.png` | Ёжик в движении и удар по слову | Свернувшийся шариком пластилиновый ёж, прозрачный фон. |
| `letter-a.png`, `letter-i.png`, `letter-s.png`, `letter-t.png` | Буквы урока «АИСТ» | Отдельные красная А, зелёная И, жёлтая С и синяя Т из фактурного пластилина, без лиц и конечностей; прозрачный фон. |

Все изображения с персонажами и рамкой генерировались как самостоятельные объекты с прозрачным фоном. Кириллические надписи в изображениях не используются.
